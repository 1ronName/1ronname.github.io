栈和堆

程序使用的内存通常被划分为几个不同的区域，称为段 segments：

  • 代码段（也称文本段）是编译后的程序在内存中存放的位置。代码段通常是只读的。
  • bss 段（也称为未初始化数据段），其中存储零初始化的全局变量和静态变量。
  • 数据段（也称为已初始化数据段），用于存储已初始化的全局变量和静态变量。
  • 堆，动态分配的变量就是从这里分配的。
  • 调用栈，其中存储着函数参数、局部变量和其他与函数相关的信息。

堆段（也称为“空闲存储区”）用于跟踪动态内存分配所占用的内存。
调用栈跟踪从程序开始到当前执行点所有已调用但尚未终止的函数，并负责所有函数参数和局部变量的分配。

命令行参数

命令行参数是可选的字符串参数，由操作系统在程序启动时传递给程序。程序可以将它们用作输入（也可以忽略它们）。就像函数参数允许一个函数向另一个函数提供输入一样，命令行参数也允许用户或程序向 程序 提供输入。

在 Microsoft Visual Studio 中，右键单击解决方案资源管理器中的项目，然后选择“属性”。打开“配置属性”树状元素，然后选择“调试”。在右侧窗格中，有一行名为“命令参数”。您可以在此处输入用于测试的命令行参数，这些参数会在程序运行时自动传递给程序。

argc 是一个整数参数，用于计数传递给程序的参数数量（可以理解为：argc = 参数数量 ）。argc 的值始终至少为 1，因为第一个参数始终是程序本身的名称。用户提供的每个命令行参数都会使 argc 的值加 1。
argv 用于存储实际的参数值（可以理解为：argv = 参数值 ，尽管它的正式名称是“参数向量”）。虽然 argv 的声明看起来有些复杂，但它实际上只是一个 C 风格的字符指针数组（每个指针指向一个 C 风格的字符串）。该数组的长度为 argc。

命令行参数始终以字符串形式传递，即使提供的值本质上是数值。要将命令行参数用作数字，必须将其从字符串转换为数字。

Lambda 捕获

Lambda 函数只能访问在 Lambda 函数外部定义的某些类型的对象，包括具有静态存储持续时间的对象（例如全局变量和静态局部变量）以及 constexpr 对象。
