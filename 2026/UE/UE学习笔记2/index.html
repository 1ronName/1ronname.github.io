断言 ensure

网络复制

属性复制：从server同步到client。（不可以反过来）

RPC：remote procedure calls。三种类型：SERVER, CLIENT, NetMulticast;

SERVER 是 Client 调用 Server；CLIENT 是 Server 调用特定 Client；NetMulticast 是 Server 调用全部 Client。

UFUNCTION(Server, Reliable)

Reliable 在没收到确认时会重发；而 Unraliable 可能丢失。

在 C++ 里实现 UFUNCTION(Server/Client/NetMulticast) 时，函数定义必须加 _Implementation 后缀。
但 声明处和调用处都不加。

TickComponent在Server和Client运行。

UPROPERTY(Replicated)

RepNotify, 在C++中是ReplicatedUsing，UPROPERTY(ReplicatedUsing="OnRep_function")

PlayerController只在Server和拥有它的Client上存在，而PlayerState在Server和所有Client上存在。

GameMode只在Server上存在。GameState则都存在。Pawn都存在。

Actor SetReplicates(true)后，会从Server复制到Client，但不会从Client复制到Server。

有用、持续的状态信息，用 RepNotify 。这样后加入服务器的玩家也能有正确的同步信息。

RPC+Unrealiable拿来传递装饰性信息，丢包了也没事的那种。

Relevancy，距离过远的Actor不复制和RepNotify (属性复制)。Reliable 多播默认被 Relevancy 限制，但可以开启选项绕过；Unreliable 多播始终受 Relevancy 限制。

AI在Server运行。

SetReplicates(true) ，AActor 的方法，设置 Actor 本身是否参与网络复制；

SetIsReplicatedByDefault(true)，UActorComponent 的方法，设置 组件本身是否默认参与网络复制，通常只在构造函数中调用

使用replicateSubobject时，uobject的outer被设置为actor（而不是原本的ActorComponent）。

RepNotify 是 在网络包发送到Client时 通过比较属性，决定是否触发 ReplicatedUsing 。如果Client本地修改了这个属性，导致网络包到达时发现属性相同，那么就不会触发 ReplicatedUsing 的函数。

OnRep_ 函数可以用一个参数来装旧值。

存档系统

Cast to 蓝图节点可以右键转换为 pure cast，此时不再有执行引脚。使用 pure cast 来预防出现静默失效的情况（cast 失败会报错，类似断言）。

World Partition 是 UE5 才引入的新一代大世界流送系统，在 UE4 中对应的替代方案是 World Composition（世界场景构成）。使用 WorldPartition 后，在 GameMode::InitGame 时，场景中Actor不全。

动画蓝图

如果蓝图变量与原生父类的变量同名且类型相同，引擎会自动移除蓝图变量，并将所有引用重定向到C++原生变量上，整个过程只会记录一条日志信息。

EventGraph处理变量；AnimGraph则用这些变量去混合动画

数据资产

Data Tables：策划填表来。

Data Assets：继承 PrimaryDataAsset 创建，数据打包。

硬引用：默认。就算只是用到了 Cast<T>，也会把T加载。

软引用：异步，用起来比较复杂，但是能提升性能。手动控制加载时机。

SIZE MAP：抓取所有 hard references 显示所有被加载的尺寸。右键资产打开

REFERENCE VIEWER：View Asset References, often reveal unnecessary Cast<T> or references to other content.

TSoftObjectPtr<T> 代替一般的指针

Async Loading 异步加载：

加载单个：FStreamableManager (C++) or Blueprint nodes such as “Async Load Asset”.

TSoftClassPtr<T> —— TSubclassOf<T>；TSoftObjectPtr<T> ——一般指针

Asset Manager，加载多个，使用Id，需要编辑器配置。

必要的数据记得在rule里设置Always Cook。

UAssetManager* Manager = UAssetManager::GetIfInitialized(); 而不是GetIfValid();

性能优化

简单方法

避免Tick调用；用Events或者Timers降低频率

碰撞设置：非必要不GenerateOverlapEvents；CollisionProfiles只对特定channels反应或者禁用小物体/无法接触的物体。尽量“QueryOnly”，除非需要物理模拟（力、重力）。

避免硬引用，这会影响加载时间和蓝图编译时间。
